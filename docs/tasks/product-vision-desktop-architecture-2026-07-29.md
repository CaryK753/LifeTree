## 决策摘要

- 桌面壳优先采用 Tauri 2，复用现有 React/Next.js UI；桌面构建逐步移除对 Next.js SSR 与 rewrite 代理的依赖，输出静态客户端。
- 短期将 FastAPI 打包为 Python sidecar，避免重写领域逻辑；Rust 宿主管理进程、密钥、升级、文件和系统集成。
- 本地模式不嵌入 PostgreSQL、Neo4j、Redis、MinIO 全家桶。使用 SQLite + 加密、本地文件对象库、嵌入式向量/图适配器和 outbox 调度器。
- 云端模式以服务器为共享数据权威，本地只保留可恢复缓存与离线 outbox；本地隐私模式以设备为唯一权威，两者不隐式切换。
- 数据迁移使用带 schema version、manifest、哈希和实体流的中立归档格式，不依赖数据库物理拷贝。
- 当前 `BackupService` 可作为导入导出的起点，但还不是同步协议，也缺少完整文件、校验、dry-run、断点恢复与冲突报告。
