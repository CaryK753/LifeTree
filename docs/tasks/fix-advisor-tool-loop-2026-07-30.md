# 修复 AI 工具调用不收敛

日期：2026-07-30
作者：wwj

## 原因

LangGraph 的 recursion limit 统计的是 Agent 图执行步数，不是 Python 函数递归深度。
当模型在“生成工具调用、执行工具、读取结果、再次生成工具调用”之间持续循环且没有
输出最终回答时，默认 25 步耗尽并抛出 `GraphRecursionError`。常见触发条件是相同
参数盲目重试、写工具成功后再次调用，或工具错误没有提供新的决策信息。
